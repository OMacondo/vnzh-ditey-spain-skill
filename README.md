# vnzh-ditey: скіл для Claude — ВНЖ для дітей в Іспанії (EX-25, ст. 160)

Покроковий помічник для українських родин з тимчасовим захистом в Іспанії. Допомагає перевести дітей на звичайний ВНЖ через онлайн-подачу **Mercurio**. Claude у діалозі:
- створює папку справи;
- збирає документи й пояснює, як отримати кожен;
- допомагає з довіреністю Apodera, цифровим сертифікатом і AutoFirma;
- готує дані для онлайн-форми EX-25 і мито 790-052;
- збирає PDF під вимоги Mercurio;
- веде по подачі, а потім по DEHú.

> ⚠️ Це не юридична консультація, а досвід однієї подачі (жовтень 2026, Валенсія). Заяви зареєстровано, але рішення ще не отримано. Правила, суми й форми можуть змінюватися, тож звіряйте з офіційними сайтами або з юристом.

## Перевірений сценарій
Скіл перевірено на одному сценарії:
- **обоє батьків і діти в Іспанії**, у всіх TIE з тимчасовим захистом, діти народжені в Україні;
- подає один із батьків через Mercurio, підписуючи своїм сертифікатом (Mac, Chrome, AutoFirma);
- другий із батьків дає згоду через довіреність Apodera.

Інші варіанти скіл теж підтримує, але в тексті вони позначені «⚠️ не перевірено», і Claude про це попереджає:
- один із батьків за кордоном;
- нотаріальна довіреність;
- інше місто;
- Windows;
- вхід без сертифіката;
- етапи після подачі.

Проблеми з сертифікатом, описані в скілі, траплялися на одному конкретному Mac. У вас їх може не бути, тому Claude звертається до них лише тоді, коли з'являється помилка.

## Як встановити

**Claude Code** (застосунок Claude → Code або термінал):
```bash
git clone https://github.com/OMacondo/vnzh-ditey-spain-skill.git ~/.claude/skills/vnzh-ditey
```
Папка має називатися саме `vnzh-ditey`, як і скіл. Потім у новій сесії напишіть `/vnzh-ditey` або просто «допоможи подати дітей на ВНЖ». Оновити скіл:
```bash
git -C ~/.claude/skills/vnzh-ditey pull
```

**Claude.ai** (веб або десктоп):
1. Завантажте архів [vnzh-ditey.zip](https://github.com/OMacondo/vnzh-ditey-spain-skill/raw/main/dist/vnzh-ditey.zip).
2. Увімкніть виконання коду та створення файлів у *Settings → Capabilities*.
3. *Customize → Skills* → «+» → *Create skill* → *Upload a skill* → виберіть zip.
