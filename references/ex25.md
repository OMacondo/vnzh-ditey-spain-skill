# EX-25: онлайн-форма в Mercurio

**EX-25**: *Solicitud de autorización de residencia y desplazamiento temporales de menores extranjeros*. Окрема заява на **кожну** дитину.

EX-25 **заповнюється прямо у вебформі Mercurio**. Система сама формує PDF заяви (*Formulario_EX25_…pdf*, кнопка «DESCARGAR SOLICITUD»). Окремий бланк заповнювати, друкувати чи завантажувати **не потрібно**. Нижче поля в тому порядку, як вони йдуть у Mercurio, щоб заздалегідь підготувати значення.

✅ Так ми заповнювали обидві заяви (діти, народжені в Україні, подавав один із батьків).

Пиши **ВЕЛИКИМИ ЛІТЕРАМИ**, латиницею, як у паспорті.

## 1. Тип дозволу
Блок **«RESIDENCIA MENOR EXTRANJERO ACOMPAÑADO (CAP I)»** → ◉ **Persona acompañada menor de edad o con una discapacidad no nacida en España (art. 160)**.

- ✅ Цей пункт підходить і тоді, коли батьки мають лише тимчасовий захист: так прямо сказано в **інструкції SEM 2/2026** (п. 2–3).
- ⚠ Для дітей, народжених в Іспанії, у списку є окремий пункт (art. 159). Ми його не перевіряли, тож таким родинам порадь уточнити в юриста.
- Галочку **«NO CONSIENTO…»** (заборона адміністрації самій перевіряти дані в держреєстрах) не став.

## 2. Вкладка «DATOS DEL SOLICITANTE» (дитина)
| Поле | Що вписати |
|---|---|
| Pasaporte | номер паспорта дитини |
| N.I.E. | NIE дитини з TIE: разом, без дефісів, з літерою в кінці |
| 1º Apellido / 2º Apellido | прізвище; друге зазвичай порожнє |
| Nombre | ім'я як у паспорті |
| Sexo | HOMBRE / MUJER |
| Fecha de nacimiento | ДД/ММ/РРРР |
| Estado civil | SOLTERO/A |
| Lugar de nacimiento | місто, як у TIE чи в перекладі свідоцтва (наприклад, KIEV) |
| País de nacimiento / Nacionalidad | UCRANIA |
| Nombre del padre / Nombre de la madre | імена батьків |
| ☐ Tiene algún tipo de incapacidad | не ставити, якщо інвалідності немає |

**Domicilio en España** (як у падроні):
| Поле | Що вписати |
|---|---|
| Tipo de vía / Domicilio / Número | тип вулиці, назва, номер будинку |
| Piso | поверх. Це випадний список, тож перевір, що значення справді вибралося |
| Letra | номер квартири або дверей. Окремого поля «Puerta» немає |
| Escalera, Bloque, Km | зазвичай порожньо |
| Provincia / Municipio / Localidad | провінція (зазвичай уже вибрана) / місто / район чи селище, якщо є в списку (інакше те саме місто) |
| C.P. | поштовий індекс |
| Teléfono móvil / E-mail | того з батьків, хто подає |

**Representante legal**:
| Поле | Що вписати |
|---|---|
| Representante legal | ім'я та прізвище того з батьків, хто подає |
| DNI/NIE/PAS | тип документа: перемкни на **NIE**, потім номер |
| Vínculo | ким **дитина** доводиться представнику: **Hijo/a biológico/a**. Інші варіанти (*Hijo con discapacidad*, *Menor tutelado por extranjero*) ⚠ не перевіряли |

## 3. Вкладка «DOMICILIO DE NOTIFICACIÓN»
1. Кнопка **«Domicilio del solicitante»** копіює адресу, але може підставити ім'я **дитини**. Виправ *Nombre/Razón Social* і *DNI/NIE/PAS* на того з батьків, хто подає.
2. ☑ **Consiento que las comunicaciones y notificaciones se realicen por medios electrónicos**. Сповіщення приходитимуть у **DEHú** на сертифікат цієї людини.
3. **CONCLUIR**.

## Підпис
Окремого підпису на бланку немає. Заяву підписують сертифікатом на останньому кроці Mercurio (*Firmar y Registrar*), а орган (Oficina de Extranjería провінції) система обирає автоматично.

## Як допомогти
Склади для кожної дитини таблицю «поле → значення → джерело» з документів у `00_Вхідні/`. Значення, яке не читається впевнено, не вгадуй: познач «перевірити» й запитай користувача. Покажи таблицю на підтвердження і збережи в `СТАТУС.md`, щоб під час подачі було звідки переписувати.
